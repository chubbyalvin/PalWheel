PALWHEEL - OPTIONAL CONTROLLER BINDING PRESET
============================================================

PURPOSE
-------

This folder contains an OPTIONAL Palworld UserOption.sav preset configured
to work well with PalWheel's default controller controls.

PalWheel does NOT require this file.

The preset frees selected Palworld controller inputs that would otherwise
conflict with PalWheel and provides a ready-to-use controller layout.


============================================================
IMPORTANT - READ BEFORE INSTALLING
============================================================

THIS PRESET REPLACES YOUR ENTIRE USEROPTION.SAV FILE.

IT DOES NOT MERGE ONLY THE CONTROLLER BINDINGS INTO YOUR CURRENT SETTINGS.

If you install this preset, ALL settings currently stored in your existing
UserOption.sav will be replaced by the values contained in the PalWheel
preset.

This means that settings you have personally changed in Palworld may be
overwritten even if they have nothing to do with PalWheel.

BACK UP YOUR EXISTING USEROPTION.SAV BEFORE INSTALLING THIS PRESET.


WHAT SETTINGS CAN BE OVERWRITTEN?
---------------------------------

UserOption.sav contains more than controller bindings.

Replacing it can overwrite settings such as:

- Controller button bindings
- Keyboard and mouse bindings stored in UserOption.sav
- Mouse sensitivity
- Mouse aiming sensitivity
- Controller / right-stick sensitivity
- Controller aiming sensitivity
- Stick threshold / deadzone-related values
- Camera-related settings
- Riding camera distance settings
- Field of View settings
- Brightness
- Other Palworld user-option values stored in UserOption.sav

Depending on your current Palworld configuration and game version, additional
settings may also be stored in this file.

THESE SETTINGS WILL NOT BE PRESERVED OR MERGED.

When you replace UserOption.sav, Palworld will use the values from the
included PalWheel preset instead of the corresponding values from your old
file.

For example, if your current UserOption.sav has your preferred sensitivity,
camera, brightness, or other settings, those values may be replaced by the
settings contained in this preset.

If you have heavily customized Palworld settings, you may prefer to manually
change the conflicting controller bindings instead of installing this file.


============================================================
CONTROLLER BINDINGS CHANGED FOR PALWHEEL
============================================================

The included preset is intended to free controller inputs used by PalWheel.

Notable controller changes include:

- Build Menu: UNBOUND
- Change Pal Left: UNBOUND
- Change Pal Right: UNBOUND
- Change Sphere: UNBOUND
- Change Weapon: UNBOUND
- Command Pal: UNBOUND
- Summon Pal / Riding Skill 2: Triangle / Y

These changes reduce conflicts with PalWheel's default controller controls.


============================================================
HOW TO INSTALL - STEAM
============================================================

1. CLOSE PALWORLD COMPLETELY.

2. Press:

   Windows Key + R

3. Paste:

   %LOCALAPPDATA%\Pal\Saved\SaveGames

4. Press Enter.

5. Locate your existing:

   UserOption.sav

6. BACK UP THIS FILE BEFORE DOING ANYTHING ELSE.

   Recommended:

   Copy UserOption.sav to another safe folder.

   Do not rely only on renaming it inside the Palworld SaveGames folder.

7. After making your backup, copy the UserOption.sav included with
   PalWheel into:

   %LOCALAPPDATA%\Pal\Saved\SaveGames

8. Windows will ask whether you want to replace the existing file.

   Choosing Replace will overwrite your current UserOption.sav and therefore
   overwrite the settings stored inside it.

9. Start Palworld.

10. Check your Palworld settings.

    In particular, check any settings you normally customize, such as:

    - Mouse sensitivity
    - Controller sensitivity
    - Camera settings
    - Field of View
    - Brightness
    - Keyboard/controller bindings

11. Open PalWheel and test the controller controls.


FULL STEAM LOCATION
-------------------

C:\Users\<Your Windows Username>\AppData\Local\Pal\Saved\SaveGames\UserOption.sav


============================================================
HOW TO RESTORE YOUR PREVIOUS SETTINGS
============================================================

If you do not like the preset or want your previous Palworld settings back:

1. Close Palworld completely.

2. Go to:

   %LOCALAPPDATA%\Pal\Saved\SaveGames

3. Remove the preset UserOption.sav.

4. Copy your original backed-up UserOption.sav back into the folder.

5. Make sure the restored file is named exactly:

   UserOption.sav

6. Start Palworld.

Your previous settings should then be restored from your original file.


============================================================
MICROSOFT STORE / PC GAME PASS
============================================================

This included UserOption.sav preset is intended for the Steam version of
Palworld.

The Microsoft Store / PC Game Pass version uses the Xbox WGS save-storage
system and does not expose UserOption.sav in the same simple file layout.

DO NOT copy this file directly into the Game Pass WGS folders using the
Steam instructions above.

Game Pass users should configure the conflicting controller bindings
manually unless a Game Pass-specific installation method is provided.


============================================================
NOTES
============================================================

- This preset is completely optional.

- PalWheel does not automatically install, replace, or modify UserOption.sav.

- Installing the normal PalWheel mod does NOT require replacing
  UserOption.sav.

- PalWheel's own settings, assignments, and custom shortcuts are separate
  from Palworld's UserOption.sav.

- Palworld updates may change the UserOption.sav format or available
  settings.

- If this preset behaves unexpectedly after a Palworld update, restore your
  original backup and configure the required controller bindings manually.
